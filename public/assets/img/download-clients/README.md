# Download client icons

Original coloured SVGs from [Dashboard Icons by Homarr Labs](https://dashboardicons.com/).
The files are bundled locally and have not been modified.

Source: https://github.com/homarr-labs/dashboard-icons/tree/cf87d9bbd47792b20893f090ff48763fe874b05d/svg

Included icons: SABnzbd, qBittorrent, Transmission, Deluge and NZBGet.
Bundling an icon does not indicate that Jellydash supports that client yet.
